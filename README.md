# 🌾 Padi Scan — Rice Plant Disease Detection

Padi Scan is a mobile application developed to help users identify potential rice plant diseases through leaf image analysis. The application integrates a machine learning model into a mobile environment to provide disease classification results based on submitted rice leaf images.

This project was developed as part of an academic final project (Tugas Akhir), combining mobile application development and machine learning to address challenges in agriculture.

---

## 📌 Project Overview

Rice is one of the most important agricultural commodities. Plant diseases can affect crop quality and productivity, making early identification an important part of agricultural management.

Padi Scan explores the use of deep learning and mobile technology to assist in identifying rice plant diseases through image classification.

The application uses a **MobileNetV2-based model** and TensorFlow Lite for mobile model integration.

## ✨ Key Features

- **Image-Based Detection** — Analyze rice leaf images to identify potential diseases.
- **Machine Learning Integration** — Integrates a deep learning classification model into a mobile application.
- **Mobile Application** — Built using Flutter for mobile deployment.
- **TensorFlow Lite** — Uses a mobile-compatible model format for inference.
- **Disease Classification** — Displays the classification result generated by the trained model.

## 🧠 Machine Learning Approach

The project uses **MobileNetV2**, a convolutional neural network architecture designed to provide efficient image feature extraction and classification.

MobileNetV2 is selected as the model architecture because of its efficiency and suitability for mobile-oriented applications.

## 🚀 Getting Started

### Prerequisites

Before running the application, make sure you have:

- Flutter SDK installed.
- Dart SDK installed.
- Android Studio or Visual Studio Code.
- Android emulator or physical Android device.

### Installation

1. Clone this repository:

```bash
git clone https://github.com/SinoriaViole/TA_DeteksiPenyakitPadi.git
```

2. Navigate to the project directory:

```bash
cd TA_DeteksiPenyakitPadi
```

3. Install dependencies:

```bash
flutter pub get
```

4. Run the application:

```bash
flutter run
```

> Make sure the required model files, assets, and Firebase configuration (if applicable) are available before running the application.
